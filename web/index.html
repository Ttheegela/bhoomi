      How to read this

      Seasons removed: we subtract each calendar month's average, so summer and winter don't hide a slow change.

      The shaded band: the range of slopes the data can support. If a flat line fits inside it, we can't call the change real.

      p-value: smaller means harder to explain by luck alone. 0.05 is the usual line for calling a change clear.

      Use Trend Detective in your own AI agent

      Connect an AI app to Trend Detective and ask it whether something is really changing at a place. The AI calls our tools. The trend, range and verdict are our calculation from public data, with the source named.

      Works with AI agents such as Claude and GitHub Copilot.

      MCP is a standard way for an AI app to use outside tools. Adding this server lets your AI look up these trends itself.

      This address is for AI apps. It is not a web page. It needs no key and no sign-in.

      Pick your AI app

      Claude

      claude.ai and Claude desktop

      1. Open Customize, then Connectors.
      2. Click "+ Add", then "Add custom connector".
      3. Enter the name "Trend Detective" and paste the server address, then click "Continue".
      4. Under Authentication choose "No sign in", then click "Add".
      5. In a chat, click "+" at the lower left, then "Connectors", and switch Trend Detective on.

      Free plans can add one custom connector. On Team and Enterprise plans an owner has to add it.

      Claude Code

      In your terminal

      1. In your terminal run the command in the box.
      claude mcp add --transport http trend-detective https://trend-detective-six.vercel.app/mcp/
      1. Start Claude Code and type /mcp. Trend Detective should show as connected.
      2. Optional: add --scope user to the command to use it in every project.

      The command claude mcp list also shows it.

      VS Code

      With GitHub Copilot

      1. Open the Command Palette and run "MCP: Add Server".
      2. Choose "HTTP (HTTP or Server-Sent Events)" and paste the server address.
      3. Name it "trend-detective", then choose Global (or the workspace if you prefer).
      4. Accept the trust prompt after reading it, then ask GitHub Copilot a question and look for Trend Detective's tools.

      Or put the VS Code block from "Prefer a settings file?" in .vscode/mcp.json. VS Code uses servers, not mcpServers.

      What you can ask once connected

      list_variables
      Lists what we can measure, such as air temperature and sea level, and where the data come from.
      get_series
      Gets the month-by-month values for a place.
      detect_trend
      Says whether it is changing at a place, how fast, and how sure we are, using the Mann-Kendall test and Sen's slope.

      Try asking:

      • Is sea level rising in New York?
      • Are the hottest days getting hotter in Delhi?
      • Has anything changed in Visakhapatnam (17.69, 83.22) since 1981?

      Your AI app may ask your permission before it calls a tool.

      What it can and can't do

      It can read public climate data from the sources named next to each result. It can't see your files, your chats or anything else on your device, and it can't change anything. It only reads.
