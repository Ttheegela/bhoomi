## Rules checklist

- Keep a visible **Built with AI assistance** watermark in every shot. Check it after each cut.
- Use plain text source credits. Do not use NASA logos or branding.
- Every data number on screen must show its source in that shot. This includes chart axes, dates, station IDs, and ranges. Keep source names and URLs readable.
- Use only the supplied results. Crop out extra numerical results. If the live app differs, do not change its output or invent a replacement. Use a clearly labeled “Reference result” title card with the supplied values and source instead.
- Keep the “no clear change” shot as a general statement. Do not attach an untested place or number to it.
- If an AI voiceover is used, add “AI-generated voiceover” to both the video description and the MP4 metadata description field. Use captions only if narration feels rushed.

## How to record

1. Set the browser recording area to 1280×720. Open https://trend-detective-six.vercel.app. Hide notifications and private tabs.
2. Click the Atlantic City sea-level example if present. Otherwise, ask “Is sea level rising in Atlantic City?” Let the result finish loading. Check it against the supplied values above.
3. Open the Princeton heat example if present. Otherwise, ask “Is the hottest day of each month getting hotter in Princeton, NJ?” Check the result against the supplied values above.
4. Record both app results with macOS Cmd+Shift+5 or OBS. Capture the verdict, chart, trend line, and source. Record extra footage so cuts are easy.
5. Trim the clips to the table's times. Cut out waits. Add the title cards, large captions, readable source footers, and the watermark throughout.
6. Add optional narration. If the voice is AI-generated, add the disclosure to the video description and file metadata.
7. Export as MP4 at 1280×720, under 30 seconds. Watch the whole file. Check the timing, sources, watermark, and final URL before uploading to the project page.
